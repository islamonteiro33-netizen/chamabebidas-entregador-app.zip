# Chama Entregador V2.1

Novidades:
- Vibração mais forte ao chegar uma corrida.
- Uma corrida por vez.
- Depois de aceitar, aparece escolha de mapa: Google Maps ou Waze.
- Botão para escolher mapa até a adega.
- Depois da retirada, botão para escolher mapa até o cliente.
- Áreas com mais chamadas usam ícone de loja/adega.

Suba os arquivos extraídos na raiz do GitHub e rode o workflow android-apk no Codemagic.

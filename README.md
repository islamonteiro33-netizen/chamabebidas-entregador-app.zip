# Chama Bebidas Entregador

App do entregador em Expo/React Native, pronto para Codemagic.

Suba todos os arquivos para a raiz do GitHub. No Codemagic selecione o workflow `android-apk`.

Arquivos obrigatórios:
- App.tsx
- package.json
- app.json
- codemagic.yaml
- tsconfig.json
- icon.png
- adaptive-icon.png
- splash.png
